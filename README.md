# Sistema-de-Atendimentos-de-Pronto-Socorro-Front-End
Front-end do Sistema de Atendimentos de Pronto-Socorro "Vihva", desenvolvido para gerenciamento e acompanhamento dos atendimentos de pacientes.


## Como abrir o protótipo

Abra `index.html` no navegador e clique em **Começar** para acessar o Painel.

O protótipo usa uma página de boas-vindas e não possui login, cadastro de conta nem autenticação simulada. O cadastro de pacientes continua disponível pelo botão **Registrar atendimento**.

## Organização do código

Cada tela possui seu conteúdo no próprio HTML. Os arquivos de apoio estão separados em:

- `assets/css`: estilos compartilhados e das telas.
- `assets/js`: comportamento das telas e funções compartilhadas.
- `assets/js/prototipo`: configuração e armazenamento simulado no navegador.
- `assets/imagens`: logo e ilustrações.

Consulte [GUIA-DO-CODIGO.md](GUIA-DO-CODIGO.md) para estudar o fluxo e os padrões de escrita. Os scripts de testes não fazem parte desta versão da pasta Front.
